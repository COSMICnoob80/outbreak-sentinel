## How to read the "angle" honestly

- **Fit, not decoration.** If the vertical isn't genuinely the subject of the
  track, the row says so (Qloo). Padding the table would defeat its purpose.
- **One repo, many stories.** The same engine serves every row because the moat
  is the loop (fuse → calibrate → receipt → resolve), not the domain label.
- **Eligibility gates are real.** CodeTheCure/EthnoHack/HETIC are students-only;
  AWS CDS is AWS Partners only. Check the "who can participate" line before
  committing effort.
